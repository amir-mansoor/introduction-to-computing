# Introduction to Computing

This repository contains course material for an introduction to computing class, including Python notebooks, C++ examples, and Java examples.

## Structure

- `*.ipynb` — Python notebooks covering core programming concepts.
- `intro-to-cpp/` — C++ examples and exercises.
- `intro-to-java/` — Java examples and compiled class files.
- `res/` — resource files such as sample CSV data and text files.

## Python Notebook Topics

- `getting-started-with-code.ipynb` — first steps with code and development environment.
- `02_library-functions-variables.ipynb` — libraries, functions, and variable usage.
- `03-functions-frames-and-scopes.ipynb` — function calls, stack frames, and scope.
- `04-lexical-global-scope-decision-making.ipynb` — scope rules and decision statements.
- `05-recursive-calls-and-backtracking.ipynb` — recursion and backtracking examples.
- `06-sequences.ipynb` — lists and sequence operations.
- `07-nested-sequence-tuples.ipynb` — nested lists and tuples.
- `08_dectionaries.ipynb` — dictionaries and key/value storage.
- `09-file-handling.ipynb` — file reading and writing.
- `10-filehandling-case-study.ipynb` — a case study on file handling.
- `11-exception-handling.ipynb` — exception handling and error control.
- `12-classes.ipynb` — object-oriented programming and class design.
- `iteration.ipynb` — loops and iteration patterns.

## How to Use

1. Open the notebook files in Jupyter or a compatible notebook viewer.
2. Run the cells sequentially to follow the lessons.
3. Use the subfolder README files for Java and C++ examples.

## Subfolders

- `intro-to-cpp/README.md` — C++ project overview and file descriptions.
- `intro-to-java/README.md` — Java project overview and file descriptions.
