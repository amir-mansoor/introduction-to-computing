# Introduction to C++

This folder contains C++ examples and exercises from the introduction to computing course.

## Contents

- `hello.cpp` — a simple hello world program.
- `02-basics.cpp` — basic C++ syntax, variables, and simple operations.
- `03-void_branching_repition.cpp` — branches and repetition using `if` and loops.
- `04-structures.cpp` — structs and grouping related data.
- `05-pointers.cpp` — pointers and memory references.
- `06_pass_by_value_reference.cpp` — passing values and references to functions.
- `output/` — example output files or generated program output.

## Notes

- Use `g++` or another C++ compiler to build the sample programs.
- Example build command:
  - `g++ hello.cpp -o hello`
  - `./hello`

## Suggested workflow

1. Open the C++ source file to study the topic.
2. Compile it with `g++`.
3. Run the executable and compare the results to the lesson.
