# Introduction to Java

This folder contains Java source files and their compiled `.class` files from the introduction to computing course.

## Contents

- `Intro01.java` — basic Java program to introduce syntax and class structure.
- `Student03.java` — example of a simple class representing a student.
- `Animal02.java` — basic class example using objects.
- `Animal04.java` — a more advanced animal class example.
- `Animal05.java` — possibly demonstrates inheritance or polymorphism.
- `Math06.java` — mathematical operations and Java expressions.

## Notes

- The `.java` files are the source code files.
- The `.class` files are compiled Java bytecode produced from those source files.
- To compile and run a Java source file:
  - `javac FileName.java`
  - `java FileName`

## Suggested workflow

1. Open the `.java` file in your editor.
2. Read the code to understand the lesson topic.
3. Compile it using `javac`.
4. Run it using `java` to observe the output.
